# Rubric Coverage

| Rubric area | Implemented behavior |
| --- | --- |
| Startup menu | New, Open, canvas preset, recent projects |
| Main canvas | Grid, snap, zoom, pan, coordinates, toolbar, status bar |
| Component library | Categories, search, schematic preview, active-list deletion |
| Component editing | Place, select, multi-select, drag, rotate, mirror, delete, properties |
| Wiring | Pin detection, orthogonal routing, junctions, dynamic rerouting, wire deletion |
| Base components | Sources, RLC data models, switch, button, LED, seven segment, logic gates, DFF |
| Simulation | Run, Pause, Stop, Step, signal colors, live interaction |
| Project tools | Validated JSON Save/Load, safer overwrite, Save As/Open, 100-state Undo/Redo, PNG export |
| DRC and log | Missing ground, floating inputs, conflicting drivers, convergence, log panel |

Advanced MCU, ADC, DAC, LCD, keypad, oscilloscope, voltmeter, and ammeter
features are outside the submitted three-member plan. Passive RLC parts are
validated data models; a complete analog MNA solver is not claimed.
